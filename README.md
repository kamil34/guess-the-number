# Guess The Number (C++)

## Description
A simple console game where the player tries to guess a randomly generated number. <br/>
Once the correct number is guessed, the score is saved to the Top 5 leaderboard.

## How to compile?

```
g++ main.cpp -o game
```

## Running the game

Linux:
```
./game
```

Windows:
```
game.exe
```

## Features

* Welcome screen
* Difficulty selection:
  * Easy (1-50)
  * Medium (1-100)
  * Hard (1-250)
* Displays the current attempt number
* Hints indicating whether the guess is too low or too high
* Top 5 leaderboard (fewest attempts)
* Option to return to the main menu after the game ends
